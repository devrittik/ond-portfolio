# Developer Portfolio

A lightweight, responsive developer portfolio built with Next.js App Router, TypeScript, Tailwind CSS, and Lucide icons.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customization

- Update personal details, social links, skills, and project content in `src/data/portfolio.ts`.
- Adjust the color palette in `src/data/theme.ts`.
- Replace `public/images/portrait.jpg` and the project preview images in `public/images/` with local assets.

Run `npm run build` to verify the production build.
